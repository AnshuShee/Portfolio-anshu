## ✨ Overview

This is my professional portfolio built with **React 19**, **Vite**, and **GSAP**. It's designed to provide a premium, interactive user experience with smooth transitions, modern aesthetics, and a deep focus on technical excellence.

---

## 🚀 Features

### 💎 Premium UI/UX
- **Smooth Scrolling**: Integrated with `@studio-freight/lenis` for a buttery-smooth desktop experience.
- **GSAP Animations**: Complex scroll-triggered animations, parallax effects, and a custom high-impact loader.
- **Custom Cursor**: Interactive cursor that reacts to links, buttons, and design cards.
- **Red & Dark Theme**: A sleek, high-contrast aesthetic with neon accents and glassmorphism.

### 📂 Dynamic Sections
- **Interactive Projects**: A curated list of clones (Myntra, GetYourGuide, Rappi) and original works.
- **UI/UX Case Studies**: Dedicated Figma section featuring interactive design modals and full-page mockups.
- **Credentials & Certifications**: A grid-based certificates section with issuer stats and hover-reveal previews.
- **Live Stats**: Integrated LeetCode statistics and real-time project filtering.

### ⚙️ Technical Highlights
- **Vite 7**: Lightning-fast build times and HMR.
- **Tailwind CSS 4**: Modern, utility-first styling with advanced CSS variables.
- **Framer Motion**: Page-to-page route transitions and subtle micro-interactions.
- **Responsive Design**: Meticulously optimized for all device sizes.

## 📦 Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/AnshuShee/Portfolio-anshu.git
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Configure Environment**
   Create a `.env` file in the root directory:
   ```env
   VITE_EMAILJS_SERVICE_ID=your_id
   VITE_EMAILJS_TEMPLATE_ID=your_template
   VITE_EMAILJS_PUBLIC_KEY=your_key
   ```

4. **Start Development Server**
   ```bash
   npm run dev
   ```
